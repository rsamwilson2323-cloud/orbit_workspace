# 🌌 ORBIT – Personal Web Workspace

A modern, browser-based workspace designed to bring useful mini-applications together in one place. **ORBIT** features a desktop-style interface with draggable windows, a floating dock, and built-in tools — all created using a single HTML file.

---

## 🚀 Features

* 🌌 Modern desktop-style interface with a custom abstract background
* 🪟 Draggable, minimizable, maximizable, and closable app windows
* 📝 Notes app with automatic local storage
* ✅ Task manager to organize daily activities
* 🧮 Built-in calculator
* 🔎 Explore app for quick web searches and useful links
* 🎨 Appearance settings with accent colour options
* 🖥️ Desktop icons and floating application dock
* ⏰ Live clock and date display
* 📱 Responsive layout for different screen sizes
* ⚡ Runs directly in a web browser — no installation required

---

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **Local Storage API**

## ▶️ Running the Application

ORBIT is a standalone HTML application.

1. Open the project folder.
2. Double-click `orbit_workspace.html`.
3. The application will open in your default browser.

You can also open it using **Google Chrome** or **Microsoft Edge**.

---

## 💡 How to Use

* Click an app icon on the desktop or dock to open it.
* Drag the window title bar to move an app window.
* Use the window controls to minimize, maximize, or close windows.
* Write and save notes in the Notes app.
* Add and manage tasks in the Tasks app.
* Perform calculations using the Calculator.
* Use the Explore app to search the web.
* Customize the accent colour through Appearance settings.
